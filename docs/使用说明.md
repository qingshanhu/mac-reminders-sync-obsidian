# 平时工作待办

打开 `工作/平时工作/待办.md`，切换到阅读视图。

任务数据保存在 `工作/平时工作/待办资料/待办清单.md`。可折叠“待办资料”文件夹，日常只打开“待办”；请保留清单和插件目录。

1. 首次点击「立即同步」，在 macOS 提示中允许提醒事项访问。
2. 在输入框填写任务，选日期和提醒事项列表，点击「添加」。Mac 和 Obsidian 新增的任务都会在下次同步时出现在另一端。
3. 勾选任务可同步完成状态；点击标题可修改名称、日期和列表。
4. 展开「同步设置与操作」，填写分钟数后点击「应用」。默认 5 分钟，允许 1–1440 分钟，修改后计时自动更新。可开启空闲延长周期：每连续 3 次无变化增加一倍周期，最多三倍；发现变化后恢复设定值。

自动同步需要 Obsidian 保持运行。暂停、休眠和关闭期间不会同步，重新聚焦或打开时会检查同步。

首次会导入 EventKit 能读取的全部提醒事项列表、未完成及已完成项目。新增任务可选择列表。不限制截止日期。

只同步标题、完成状态、截止日期和列表。Mac 原有备注、附件、提醒闹钟、标签和重复规则不会被主动改写；子任务结构及这些信息不显示在此界面。修改日期不会自动创建提醒闹钟。

删除请在 Mac 提醒事项操作；删除会在下次同步从清单移除。单独删除 Markdown 行不会删除 Mac 任务，下次会补回。双方同时修改同一字段时采用 Mac 版本，原值保存在 `.obsidian/plugins/work-reminders-sync/conflicts.jsonl`。上一次重写前的清单保存在同目录 `last-backup.md`。

出现权限错误时：系统设置 → 隐私与安全性 → 提醒事项，允许「Obsidian 待办同步」或 Obsidian，再点击「立即同步」。

插件：`.obsidian/plugins/work-reminders-sync`。关闭方式：Obsidian 设置 → 第三方插件 → 平时工作 · 提醒事项同步 → 关闭。
