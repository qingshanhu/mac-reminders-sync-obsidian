# 故障排查

## 代码块原样显示

确认桌面版 Obsidian 已允许第三方插件并启用「Mac 待办同步 Obsidian」。代码块语言为 `mac-reminders`，切换到阅读视图。

插件目录必须直接为 `.obsidian/plugins/work-reminders-sync/`，没有额外套层，并包含 `main.js`、`manifest.json`、`styles.css` 和 `RemindersBridge.app`。

## 权限未授权

系统设置 → 隐私与安全性 → 提醒事项，允许「Obsidian 待办同步」或 Obsidian，然后重新打开并点击「立即同步」。权限须由用户授予，不要直接修改 macOS 权限数据库。

## 桥接程序无法运行

下载的桥接只有本地签名，没有 Developer ID 公证。如果系统阻止运行，请从源码在自己的 Mac 构建，不要关闭安全保护。确认 macOS 14+、下载完整、二进制有执行权限。

源码构建时确认 `xcrun --find swiftc` 能找到编译器。`npm run build:universal` 会构建两种架构并校验签名。

## 新增或完成没有马上同步

等待下一个周期，或点「立即同步」并检查页面错误。默认 5 分钟。开启空闲延长后最多达到设定值三倍。Obsidian 必须运行，提醒事项权限必须已允许。

## iPhone 改动未出现

先确认任务在本 Mac 提醒事项出现。Apple 账户同步由系统负责；本插件只访问本机 EventKit。

## 删除清单行后重新出现

删除以 Mac 为准，Markdown 删行不触发 Mac 删除。在 Mac 删除后再次同步。

## 同时修改后采用 Mac 版本

同一字段同时修改采用 Mac 值，本地旧值保存在插件 `conflicts.jsonl`，上次清单备份在 `last-backup.md`。先暂停同步，再核对旧值，必要时重新修改。

## 重复任务标识

复制整行会复制 `<!-- mr:... -->`，使两条任务指向同一 ID。要创建新任务，删除新复制行的标识；保留原始行的标识。特殊标题还可能带 `<!-- mt:... -->` 用于保存原值，日常请使用界面编辑。

## 升级或迁移

升级保留 `data.json` 与清单。退出 Obsidian 再替换程序。迁移目录前先同步、暂停并备份清单，移动原文件后更新目标路径。安装器 `--folder` 不会自动移动旧任务。

## 报告问题

提供 macOS、芯片、Obsidian、插件版本、错误文本和复现步骤。使用虚构任务，勿上传真实清单、`data.json`、备份、冲突日志或私人截图。
