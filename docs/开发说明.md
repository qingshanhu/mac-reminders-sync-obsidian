# 开发说明

## 结构

- `src/core.js`：Markdown 编解码、稳定映射、逐字段三方合并。
- `src/plugin.js`：Obsidian 生命周期、界面、定时器和原生进程调用。
- `src/styles.css`：跟随 Obsidian 主题的局部样式。
- `native/RemindersBridge.swift`：EventKit 标准输入/输出 JSON 桥接。
- `native/Info.plist`：应用身份及提醒事项用途说明。
- `scripts/build.mjs`：CommonJS 合并、Swift 编译和本地签名。
- `scripts/install.mjs`：安装与升级，保留已有笔记和运行态数据。
- `scripts/package.mjs`：按白名单生成 ZIP。
- `templates/`：空白模板。
- `tests/`：合成任务及临时假笔记库测试。

## 命令

```bash
npm test
npm run check
npm run build            # 当前架构
npm run build:universal  # arm64 + x86_64，最低 macOS 14
npm run package          # 完整包与插件包
```

构建须在 macOS 使用 Xcode Command Line Tools；打包需要 Python 3 标准库，没有 npm 或 pip 第三方依赖。ZIP 明确标记 UTF-8 文件名并保留执行权限。产物在 `dist/`，中间文件在 `build/`，都不提交 Git。

## 原生协议

插件通过标准输入发送 JSON，标准输出返回 JSON。错误写入标准错误并以非零码退出。

```json
{"operation":"snapshot"}
```

返回 `items`、`lists`、`applied`（本地 key → Apple ID）。

```json
{"operation":"apply","updates":[{"key":"合成任务UUID","title":"演示任务","done":false,"listId":"列表ID","due":"2026-10-20 09:30"}]}
```

修改既有任务提供 `id`，只发送变更字段；清除日期用 `clearDue: true`。新建任务 URL 带本地 key，可在原生写入成功但本地记录尚未保存时恢复，减少重复创建。已有 Apple 任务 URL 不改写。

## 同步逻辑

读取 Mac 快照和 Markdown → 补充本地标识 → 比较上一轮 `base` 和两端当前值 → 应用 Apple 修改 → 读取最终快照 → 写回清单并保存状态。

不同字段合并，同字段冲突以 Mac 为准并记录原本地值。Mac 删除为准，本地删行不删除 Apple 数据。同步过程中新增或修改的本地任务会合并保留。只读列表不能写入。权限失败不作为空清单处理。

## 验证范围

自动测试只使用合成任务和临时假笔记库，不请求系统权限、不访问真实提醒事项。初版已在作者 Apple Silicon 本机实测新增、完成状态、标题日期回传、无重复实例及验证任务清理。Intel 交叉编译不代表 Intel 实机验证。

实机回归请使用专门测试列表，核对新增、完成、清除日期、同名任务、权限拒绝和睡眠唤醒。

## 发布

更新 `manifest.json`、`package.json`、`native/Info.plist` 和 `CHANGELOG.md`，测试及构建后提交，推送 `vX.Y.Z` 标签。Release 工作流构建通用包并上传两个 ZIP。

工作流只需 `contents: write`，不需要 Apple ID、iCloud 凭据或提醒事项数据。不要使用真实笔记库打包，不提交运行态 JSON、日志、备份或私人截图。
